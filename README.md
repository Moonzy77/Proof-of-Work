# PoW.py

Консольный проект, реализующий криптографическое ядро блокчейна: хэш-функцию Стрибог-256, подпись Шнорра, дерево Меркла и алгоритм консенсуса Proof of Work.

## Состав проекта

- `PoW.py` — основная консольная программа

## Что реализовано

- хэш-функция Стрибог-256 (ГОСТ Р 34.11-2012)
- генерация псевдослучайных чисел на основе Стрибог-256
- подпись Шнорра key-prefixed
- создание и подпись 5 транзакций
- дерево Меркла для агрегации хэшей
- формирование заголовка блока и подбор nonce (PoW)
- интерактивное меню для пошаговой работы
- автоматическое сохранение результатов в `crypto5_result/`

## Зависимости

Проект использует только стандартную библиотеку Python:

- `os`
- `time`

Установка сторонних библиотек не требуется.

## Запуск

```bash
python3 PoW.py
```

## Как использовать

При запуске программа запросит ФИО — от него зависят все псевдослучайные данные. После этого откроется главное меню:

1. Просмотр параметров задания.
2. Работа с хэш-функцией Стрибог-256.
3. Генерация псевдослучайных чисел.
4. Генерация ключевой пары и подпись Шнорра.
5. Создание транзакций и построение дерева Меркла.
6. Формирование блока и подбор nonce (PoW).
7. Полный автоматический прогон всех этапов.
8. Сброс текущей сессии.
9. Выход.

Результаты работы сохраняются в папку `crypto5_result/` рядом со скриптом.

## Как это работает

**Стрибог-256.** Сообщение разбивается на 512-битные блоки. Для каждого блока выполняются преобразования подстановки ($S$), перестановки ($P$) и линейного преобразования ($L$), после чего применяется сжимающее преобразование с учётом счётчика обработанных данных. Финальное усиление учитывает длину сообщения и контрольную сумму.

**Генерация псевдослучайных чисел.** Начальное значение $h_0$ получается хэшированием ФИО пользователя, дополненного до 512 бит. В последующих циклах вычисляются $h_i = H(h_0 \parallel i)$, где $i$ — номер цикла. Биты псевдослучайных чисел расходуются последовательно без повторного использования.

**Подпись Шнорра.** Генерируется закрытый ключ $x$ и открытый ключ $y = g^x \pmod p$. Для подписи выбирается случайный нонс $k$, вычисляется $R = g^k \pmod p$ и хэш-вызов $e = H(R \parallel y \parallel m)$. Подпись — пара $(R, s)$, где $s = k + ex \pmod q$. Проверка выполняется сравнением $g^s$ и $R \cdot y^e \pmod p$.

**Дерево Меркла.** Для каждой подписанной транзакции вычисляется хэш объединения «транзакция + подпись». Из полученных хэшей строится бинарное дерево: соседние элементы конкатенируются и хэшируются, при нечётном количестве последний дублируется. Корень дерева включается в заголовок блока.

**Proof of Work.** Заголовок блока состоит из размера блока, хэша предыдущего блока, корня Меркла, временной метки и nonce. Программа перебирает nonce до тех пор, пока хэш Стрибог-256 заголовка не начнётся с 5 нулевых бит.
